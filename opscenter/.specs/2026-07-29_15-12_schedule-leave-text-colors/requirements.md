# 排班週期假別文字色需求

## 文件定位

本規格接續 `.kiro/specs/2026-06-25_11-04_fixed-shift-schedule-leave-management` 的排班矩陣視覺規則，針對排班週期表內「休／國／例」三種假別的文字色提出新需求，並依 Material Design 色票為淺色與深色主題選擇對應色階。

既有 task `7.11 強化排班格假別色彩與主題相容` 已完成，本規格不修改該 task 的完成狀態，而是以新的未完成 task 覆寫其中「文字色依深淺主題切換」的部分。背景色、邊框色、其他假別與出勤班別維持既有邏輯。

## 詞彙與假設

假設：使用者所述「文字 選」是指排班週期表格按鈕內顯示的「休」、「國」、「例」單字文字顏色，不是下拉選單文字、統計 Chip、日期欄或假別選項顏色。

主題對應現有 `ThemeMode`：

- 暗色毛玻璃：`dark-glass`
- 深色：`dark`
- 淺色：`light`
- 淺色毛玻璃：`light-glass`

## 背景

第一版已將「休／國／例」改為紫、粉紅、藍綠文字色，並讓毛玻璃與非毛玻璃主題依 `theme.palette.mode` 共用色碼。使用者檢視新的設計色票後，要求先套用黃、藍、綠語意色，且四種 `ThemeMode` 各自使用指定色碼供畫面預覽。

本次指定色碼：

| 主題 | 國 `public_holiday` | 例 `statutory_holiday` | 休 `day_off` |
|---|---|---|---|
| 深色 `dark` | `#FFD54A` | `#BFE3FF` | `#83FFD5` |
| 暗色毛玻璃 `dark-glass` | `#FFE082` | `#D6ECFF` | `#A8FFE4` |
| 淺色 `light` | `#B45309` | `#1D4ED8` | `#047857` |
| 淺色毛玻璃 `light-glass` | `#9A3412` | `#1E40AF` | `#065F46` |

## 目標

1. 四種主題分別使用指定的黃、藍、綠文字色。
2. 可編輯、唯讀、hover 與 disabled 狀態不得改變目前 `ThemeMode` 的指定文字色碼。
3. 三種語意色以排班元件 token 集中管理，直接依四種 `ThemeMode` 查詢。
4. 不擴充全域 MUI Theme；由排班頁面將目前 `themeMode` 傳給排班格樣式。
5. 毛玻璃與非毛玻璃主題使用不同色碼，不再只依 `palette.mode` 收斂為兩組。
6. 深色按鈕背景、其他 day type 與出勤班別維持既有主題相容邏輯。
7. 淺色與淺色毛玻璃的「國／例／休」按鈕提高背景與邊框透明度，讓三種語意色在白色系背景上可辨識。
8. 國／例／休配額 Chip 改為與排班格一致的 tonal 配色，避免所有缺額都顯示為高飽和實心橘色。

## 非目標

- 不改變「年／公／病／事／他」文字顏色。
- 不改變早班、中班、晚班等出勤格顏色。
- 不改變假別下拉選單、國／例／休統計 Chip 或日期欄顏色。
- 不調整全域 MUI palette。
- 不修改後端 API、資料庫或排班規則。
- 不改變深色、暗色毛玻璃、其他假別與工作日的按鈕背景、邊框或尺寸。
- 不改變配額、每週檢查的計算規則、標籤內容、Tooltip、欄位位置或排列方式。

## 現有行為與新行為

| 項目 | 現有行為 | 新行為 |
|---|---|---|
| 「休」文字 | light `#512DA8`、dark `#B388FF`，毛玻璃共用 | 四主題依序使用 `#83FFD5`、`#A8FFE4`、`#047857`、`#065F46` |
| 「國」文字 | light `#C2185B`、dark `#FF80AB`，毛玻璃共用 | 四主題依序使用 `#FFD54A`、`#FFE082`、`#B45309`、`#9A3412` |
| 「例」文字 | light `#00796B`、dark `#64FFDA`，毛玻璃共用 | 四主題依序使用 `#BFE3FF`、`#D6ECFF`、`#1D4ED8`、`#1E40AF` |
| 「國／例／休」淺色按鈕 | 一般背景 `16%`、邊框 `72%`；hover 背景 `24%`；disabled 背景 `10%`、邊框 `42%` | 一般背景 `24%`、邊框 `82%`；hover 背景 `32%`；disabled 背景 `16%`、邊框 `58%` |
| 深色按鈕背景與邊框 | 依既有 dark leave tone 計算 | 維持不變 |
| 其他假別 | 依既有 tone 計算 | 維持不變 |
| 國／例／休缺額 Chip | MUI `warning` filled，三種皆為實心橘色 | 依國紅、例藍、休青使用淡色背景、彩色邊框與主題文字色 |
| 每週檢查 Chip | MUI `warning`／`error`／`success` 預設樣式 | 保留狀態語意，改為同層級 tonal 樣式 |

## 使用情境

使用者切換暗色毛玻璃、深色、淺色或淺色毛玻璃主題時，可以用一致的黃、藍、綠語意快速辨識「國／例／休」，並由四組色階配合各自主題背景。排班週期進入唯讀狀態時，不再額外降低指定文字色透明度。

## 驗收情境

### 場景 A：四種主題顯示指定色

測試：人工主題矩陣驗收，待本次變更 task `4.2` 執行。

假設排班週期表同時存在「休」、「國」、「例」格子。

當使用者依序切換 `dark-glass`、`dark`、`light`、`light-glass`。

那麼「國／例／休」在 `dark` 為 `#FFD54A`／`#BFE3FF`／`#83FFD5`，在 `dark-glass` 為 `#FFE082`／`#D6ECFF`／`#A8FFE4`，在 `light` 為 `#B45309`／`#1D4ED8`／`#047857`，在 `light-glass` 為 `#9A3412`／`#1E40AF`／`#065F46`。

### 場景 B：唯讀狀態不降低指定文字色

測試：人工唯讀週期驗收，待本次變更 task `4.2` 執行。

假設週期為 `confirmed` 或 `locked`，排班按鈕處於 disabled。

當畫面顯示「休」、「國」、「例」。

那麼文字不得套用降低透明度後的顏色，仍須使用目前深淺主題對應的完整指定色碼。

### 場景 C：其他排班格不受影響

測試：`npm run typecheck`、`npm run build` 與人工回歸抽查。

假設排班表包含工作日與其他假別。

當新文字 token 套用完成。

那麼工作日、「年／公／病／事／他」的文字、背景與邊框維持既有顯示邏輯。

### 場景 D：淺色按鈕語意色可辨識

測試：使用者提供的淺色主題畫面預覽。

假設排班週期表同時顯示「國」、「例」、「休」的 disabled 按鈕。

當使用者切換至 `light` 或 `light-glass`。

那麼三種按鈕應呈現可辨識的淡紅、淡藍、淡青背景與對應邊框；只有「國／例／休」使用加強後的透明度，其他假別維持既有值。

### 場景 E：配額 Chip 與排班語意色一致

測試：使用者已完成 task `5.3` 四主題與缺額、超排、正確狀態人工驗收。

假設使用者的國定假、例假與休假皆有缺額，且每週檢查也未通過。

當排班矩陣顯示配額與每週檢查 Chip。

那麼國缺額使用紅色 tone 與目前主題的國文字色，例缺額使用藍色 tone 與例文字色，休缺額使用青色 tone 與休文字色；每週缺少維持 warning 琥珀色。Chip 使用淡色背景、`1px` 邊框、pill 圓角、字重 `600`、無陰影，且不得因外觀改變計算或 Tooltip。
