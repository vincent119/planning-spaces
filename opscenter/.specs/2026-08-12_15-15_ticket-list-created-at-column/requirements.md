# Ticket 列表建立時間欄位需求

## 文件定位

本規格新增前端 Ticket 列表的建立時間欄位，接續既有列表外部單號與更新時間欄位。只調整列表顯示，不修改 Ticket API、資料庫或查詢口徑。

## 背景

Ticket 列表目前在「外部單號」後直接顯示「更新時間」。API 與前端 `Ticket` 型別已提供 `created_at`，但列表未顯示，使用者無法直接比較建立與更新時間。

## 目標

1. 在更新時間左側新增「建立時間」。
2. 建立時間沿用更新時間的語系日期時間格式。
3. 維持現有列表篩選、分頁、URL 狀態與操作行為。

## 非目標

- 不新增建立時間搜尋或排序功能。
- 不修改後端 API、資料庫或 OpenAPI。
- 不修改 Ticket 詳情頁及其他表格。

## 驗收條件

- [x] 1.1 Ticket 列表欄位順序為「外部單號 → 建立時間 → 更新時間 → 操作」。
- [x] 1.2 建立時間讀取每列 `created_at`。
- [x] 1.3 建立時間使用目前語系格式化，無效值安全顯示原值或 `-`。
- [x] 1.4 欄位標題使用既有 `ticket.field.created_at` 三語系文案。
- [x] 1.5 不修改 API request、分頁、篩選、URL 查詢狀態與其他欄位。
- [x] 1.6 TypeScript 檢查與正式 build 通過。

## 驗證需求

- 檢查欄位順序與 renderCell。
- `npm run typecheck`。
- `npm run build`。
- `git diff --check`。
