# Draft: Native DateField Calendar

Status: Draft

## Source

- `.kiro/specs/2026-07-23_11-59_native-datefield-calendar`

## Intent

重新規劃 DateField 使用原生或自製日曆的策略、瀏覽器行為、可及性與表單一致性。

## Bounded Context

包含：

- Native date input behavior
- Custom calendar fallback
- Date formatting
- Mobile and desktop interaction

不包含：

- DateTime picker
- Calendar scheduling module
