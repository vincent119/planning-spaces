# 需求文件：CareNest 三種顯示模式

Status: Planned

## 文件定位

- 取代「CareNest 預設深色主題」中「強制預設深色」的產品決策。
- 延續既有全域色彩 Token、量測趨勢圖、每日照護、多位被照顧者與本機資料功能。
- 本文件只規範顯示模式與色彩系統，不重寫照護流程或資料模型。

## 背景

- 使用者明確定義兩張參考圖分別代表淺色與深色主題，並要求提供第三種「跟隨系統」模式。
- 目前 App 強制使用深色模式，與此產品定義不符，需改為可選擇且可保存的顯示偏好。

## 目標

- 提供「淺色主題」「深色主題」「跟隨系統」三個互斥選項。
- 預設為「跟隨系統」；首次使用時不需額外設定。
- 使用者變更後立即套用，且下次啟動 App 仍保留選擇。
- 淺色與深色主題共享相同排版、功能、文案與狀態語意，只改變色彩與表面層級。
- 提供獨立的文字大小選項，讓照護者在不改變主題配色的前提下調整閱讀舒適度。

## 非目標

- 不新增帳號、雲端同步、後端服務、遠端 API 或分析服務。
- 不依被照顧者個別設定主題；顯示偏好屬於裝置上的 App 層級設定。
- 不增加自訂色盤、字型大小調整或其他外觀設定。
- 不提供任意比例滑桿或個別頁面字級設定，避免破壞既有行動版面與驗證範圍。
- 不改變照護記錄、照片、量測、被照顧者或資料庫既有資料的內容。

## 使用情境與驗收

### 場景：首次開啟

- 測試：待建立 Widget 測試。
- 假設：裝置尚未保存任何顯示模式偏好。
- 當：照護者首次開啟 CareNest。
- 那麼：App 使用「跟隨系統」模式；系統為淺色時顯示淺色主題，系統為深色時顯示深色主題。

### 場景：選擇淺色主題

- 測試：待建立 Widget 與本機保存測試。
- 假設：照護者已進入顯示設定。
- 當：選擇「淺色主題」。
- 那麼：App 立即固定為淺色主題，不受系統深色設定影響；重新開啟後仍維持淺色主題。

### 場景：選擇深色主題

- 測試：待建立 Widget 與本機保存測試。
- 假設：照護者已進入顯示設定。
- 當：選擇「深色主題」。
- 那麼：App 立即固定為深色主題，不受系統淺色設定影響；重新開啟後仍維持深色主題。

### 場景：選擇跟隨系統

- 測試：待建立 Widget 測試。
- 假設：照護者原先選擇固定淺色或固定深色。
- 當：選擇「跟隨系統」。
- 那麼：App 立即回到系統主題，並在系統主題改變時自動切換。

### 場景：調整文字大小

- 測試：待建立 Widget 與本機保存測試。
- 假設：照護者已進入顯示設定。
- 當：選擇「標準」「較大」或「特大」文字。
- 那麼：App 立即以對應比例顯示文字，主題顏色不改變，重新開啟後仍維持選擇。

### 場景：特大文字下操作既有功能

- 測試：待建立 Widget 與 Android 手動驗證。
- 假設：照護者選擇「特大」文字。
- 當：瀏覽首頁頂端導覽、照護卡片、量測趨勢圖、對話框與顯示設定。
- 那麼：文字不被裁切，操作控制項仍可點擊，必要時元件自然換行或增加高度。

### 場景：瀏覽既有照護功能

- 測試：既有全量測試與 Android 手動驗證。
- 假設：照護者在任一顯示模式下使用首頁、被照顧者、量測、回顧、明細與首次設定。
- 當：查看卡片、輸入欄、對話框、按鈕、選取狀態與量測圖。
- 那麼：資訊與操作不會只由顏色傳達，所有既有功能與本機資料均維持可用。

## 驗收條件

- 主題設定入口清楚標示為「顯示設定」或同等語意。
- 三種選項互斥，並透過單選控制項與文字顯示目前選擇。
- 固定淺色與固定深色的選擇可跨 App 重啟保留。
- 預設未設定時為 `ThemeMode.system`。
- 文字大小提供標準 100%、較大 115%、特大 130% 三個互斥選項；預設標準 100%。
- 文字大小選擇可跨 App 重啟保留，且不改變目前的淺色、深色或跟隨系統模式。
- 淺色主題使用冷灰白底、淡藍表面與藍色主要操作色；深色主題使用深墨藍底、青綠主要操作色。
- 暖珊瑚僅代表血壓第二資料線或錯誤提示，不代表健康風險。

## 驗證需求

- 驗證主題模式映射與本機保存／讀取。
- 驗證文字縮放比例映射與本機保存／讀取。
- 驗證三種模式都能產生正確的 `ThemeMode`。
- 執行 `dart format`、`flutter analyze`、`flutter test`、`flutter build apk --profile` 與 `git diff --check`。
- Android 實機依序檢查淺色、深色與跟隨系統模式。
