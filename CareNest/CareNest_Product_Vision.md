# CareNest - Product Vision

## 專案定位

CareNest 不是醫療 App，而是 **家庭照護助手（Family Care Companion）**。

主要服務對象不是長輩，而是 **40--60 歲需要照顧父母的家人**。

產品目標：

-   降低照護負擔
-   快速記錄每日狀況
-   提供長期趨勢
-   幫助家屬掌握照護品質
-   不提供醫療診斷、不取代醫師

------------------------------------------------------------------------

# 核心理念

> 讓家人知道「今天有沒有照顧好」，而不是只記錄健康數據。

------------------------------------------------------------------------

# MVP（第一版）

不建立自己的 Backend。

所有資料：

-   Local Database
-   iCloud / CloudKit（後續）
-   Google Drive 備份（後續）

## 功能

### 1. 飲食紀錄

-   早餐
-   午餐
-   晚餐
-   點心

支援：

-   吃幾成
-   拍照
-   備註

------------------------------------------------------------------------

### 2. 高蛋白紀錄

例如：

-   葡納勝
-   安素
-   亞培
-   Ensure

紀錄：

-   幾瓶
-   時間
-   熱量
-   蛋白質

------------------------------------------------------------------------

### 3. 喝水

快速增加：

-   +100 ml
-   +200 ml
-   +300 ml

------------------------------------------------------------------------

### 4. 體重

每日一次即可。

------------------------------------------------------------------------

### 5. 血壓

早晚紀錄。

------------------------------------------------------------------------

### 6. 用藥

-   已服用
-   未服用
-   提醒

------------------------------------------------------------------------

### 7. 每日完成度

例如：

-   早餐
-   午餐
-   晚餐
-   高蛋白
-   喝水
-   用藥

產生：

> 今日完成度 82%

-   Offline-first

-   不建立 API Server
-   不建立 PostgreSQL
-   不建立 Kubernetes
-   不需要帳號登入

------------------------------------------------------------------------

# 產品特色

CareNest 聚焦於：

-   每天是否有吃飯
-   是否攝取足夠蛋白質
-   是否喝足夠水
-   體重是否下降
-   家人是否完成照護

而不是醫療診斷。

------------------------------------------------------------------------
